# Try-it-locally clip

`try.tape` records `apps/site/public/media/blog/choosing-your-first-stack/try.mp4`
with [VHS](https://github.com/charmbracelet/vhs) and conn3x v0.4.0, inside a
copy of `examples/try-it-locally` from conn3xorg/conn3x after `./up.sh` and
`conn3x init`. The sleeps are sized to a local Podman run; lengthen them if a
step hasn't finished. Encode as in `../../why-conn3x/clip/README.md`, poster
from the last frame. Run `./down.sh` afterwards.
