CONN3X · CHOOSING YOUR FIRST STACK

The loop you learn once

Four moves cover everything, from a cloud server to the file on it. Learn them on a throwaway container in five minutes.

01

Write

Say what you want, in HCL: servers, packages, files, users.

step "motd" {...}
02

Plan

Conn3x reads what's really there and shows the difference.

conn3x plan
03

Apply

It makes exactly those changes, and records them in state.

conn3x apply
04

Plan again

Nothing left to do. That's how you know it worked.

No changes.

When someone edits by hand

conn3x drift reports it and exits 2. The next plan shows the exact line, and apply puts it back. Same loop.
