# Drift clip

`drift.tape` records `apps/site/public/media/blog/catch-the-3am-fix/drift.mp4`
with [VHS](https://github.com/charmbracelet/vhs) and conn3x v0.5.0, in a copy of
`examples/try-it-locally` from conn3xorg/conn3x, after `./up.sh`, `conn3x init`
and `conn3x apply`. The tape makes the hand edit itself, over SSH to the
throwaway container on 127.0.0.1:2222. Run `./down.sh` afterwards. Encode as in
`../../why-conn3x/clip/README.md`, poster from the last frame.
