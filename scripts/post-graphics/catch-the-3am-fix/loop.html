CONN3X V0.6.1 · DRIFT IN CI

The nightly loop

A scheduled job runs conn3x drift every morning. Its exit code decides what happens next.

06:17 UTC

The schedule

A GitHub Actions cron starts the job.

→runs
BOTH LAYERS

conn3x drift

Reads the cloud and every host step again. Changes nothing.

EXIT 0

No drift

The cloud and the hosts match the last apply. Nothing to do.

EXIT 1

The check broke

A host didn't answer, say. The job fails, no issue.

EXIT 2

Drift found

The job fails and opens an issue with the report.

AFTER EXIT 2 · YOU, NEXT MORNING

conn3x plan

Shows exactly what changed, line by line for a file.

Put it back

The hand edit was wrong, or a stopgap. conn3x apply restores what the circuit says.

Keep it

The hand edit was right. Copy it into the circuit, plan until No changes., then apply to record it.

Next morning: drift comes back clean, and exits 0.
