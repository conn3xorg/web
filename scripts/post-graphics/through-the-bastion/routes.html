CONN3X · REACHING PRIVATE HOSTS

Three ways to write the route

Pick the one that matches where your team keeps it today. Settings in the circuit win over the file.

1 · IN THE SSH BLOCK

jump_hosts

Every host goes through the same bastion, written like ssh -J.

ssh {
  user       = "admin"
  jump_hosts = [
    "admin@bastion.example.com",
  ]
}
2 · PER HOST

Host objects

Override the route for one host, such as the bastion itself.

hosts = {
  bastion = {
    address    = "203.0.113.10"
    jump_hosts = []  # direct
  }
  app1 = "10.0.1.5"
}
3 · FROM A FILE

ssh_config_file

Use the aliases you already have. Read only when you name the file.

Host app*
  User admin
  ProxyJump bastion

ssh_config_file = "./ssh_config"

Every hop is checked

The bastion's host key and each server's are verified against your known_hosts file. There's no setting to skip it. One connection per host is opened through the bastion and shared by every step.
