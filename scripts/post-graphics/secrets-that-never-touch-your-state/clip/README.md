# Secrets clip

`secrets.tape` records `apps/site/public/media/blog/secrets-that-never-touch-your-state/secrets.mp4`
with [VHS](https://github.com/charmbracelet/vhs) and conn3x v0.4.0, in a copy of
`examples/secrets` from conn3xorg/conn3x, after `../try-it-locally/up.sh` and
`conn3x init`. The tape sets a throwaway `CONN3X_HMAC_KEY` so the recording
doesn't use your own key file. Encode as in `../../why-conn3x/clip/README.md`,
poster from the last frame.
