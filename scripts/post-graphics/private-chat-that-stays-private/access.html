WHO CAN SIGN UP?

Nobody

The first admin is made from your inputs before the port opens, so no stranger gets there first. Everyone else, an admin adds.

enable_signup = false
WHICH MODELS DO PEOPLE SEE?

None, until given

Admins see every model. A user sees only what an admin grants them or their group in the admin panel.

share_models_with_all_users = false
WHERE ARE THE CHATS?

On your host

SQLite in the open-webui volume, or PostgreSQL with database_url. Admins can read chats unless you turn that off.

ENABLE_ADMIN_CHAT_ACCESS = "false"
WHAT LEAVES THE BOX?

Only prompts you route out

Telemetry, the update check and community sharing are off. With no OpenAI address set, the api.openai.com default is turned off too.

offline_mode = true
