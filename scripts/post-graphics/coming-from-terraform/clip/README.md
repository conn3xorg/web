# Plan clip

`plan.tape` records `apps/site/public/media/blog/coming-from-terraform/plan.mp4`
with [VHS](https://github.com/charmbracelet/vhs) and conn3x v0.4.0, in a copy of
`examples/digitalocean` (this `main.tf`) after `conn3x init`, with a `deploy.pub`
beside it. `-refresh=false` and a placeholder token let it plan without an
account. Encode as in `../../why-conn3x/clip/README.md`, poster from the last frame.
