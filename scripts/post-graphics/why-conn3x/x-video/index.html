ONE PLAN

The servers and their setup, side by side.

A circuit is a playbook in HCL. Its hosts are an expression, so there's no inventory to keep in sync.

resource "digitalocean_droplet" "app" {
  count = 3
  name  = "app-${count.index}"
  image = "rockylinux-10-x64"
}

circuit "app" {
  hosts = { for d in digitalocean_droplet.app :
            d.name => d.ipv4_address }
  ssh { user = "root" }

  step "deploy_user" {
    user { name = "deploy" }
  }
}
ONE APPLY

Create, wait, check the host key, configure.

One run. One state file. The next plan has nothing to do.
