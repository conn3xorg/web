MOMENTTERRAFORM + ANSIBLECONN3X
01

Create the servers

terraform apply creates three droplets and records them in Terraform state.
conn3x apply creates them with the same providers, built on OpenTofu.
02

Wait for SSH

A sleep or a retry loop, tuned by hand until it mostly works.
The ssh block's timeout keeps trying a host that isn't answering yet, 3 minutes by default.
03

Pass the addresses

local-exec or an inventory script writes inventory.ini.
hosts is an expression over the droplets. Nothing to write.
04

Configure

ansible-playbook -i inventory.ini site.yml, with Python on the controller and the hosts.
Same apply. Each step runs on every host over SSH, after its host key is checked. No agent, no Python.
05

Preview

terraform plan, then a separate --check --diff run for the hosts.
One conn3x plan: the droplets and the changes headed for each one.
06

Remember

Terraform state for the cloud. None for the hosts.
One state file for both layers.
07

Scale 3 to 2

Terraform removes app-3. A static inventory keeps listing it until someone edits it.
The same plan removes app-3, deleting its keys from the server first.
08

Catch hand edits

terraform plan for the cloud, then the playbook in check mode for the hosts.
conn3x drift checks both layers and exits 2 when something changed.
