CONN3X V0.6.3 · HOW IT'S TESTED

Three gates

A change reaches your servers only after it has passed all three. Each one catches what the one before it can't.

GATE 1

Every pull request

Required checks. Nothing merges red.

Real hosts in Podman

Circuits applied over SSH to systemd containers, then checked on the host. Run twice: host agent off, and host agent required.

Rocky 10Fedora 45Ubuntu 24.04Debian 13

Every example

Each docs example and each examples/ directory must validate.

Four upstream edits

Every OpenTofu file Conn3x changes is marked. More than five fails.

Smaller than tofu

The build fails if conn3x grows past the tofu it's built from.

↓
GATE 2

Every night

Real machines, real bills, deleted after.

Two DigitalOcean droplets

One plan creates a Rocky Linux 10 and an Ubuntu 24.04 droplet and sets them up: firewalld and ufw, SELinux, a mount, sysctl, sudo, a reboot.

Then it checks

Fetches the page through the firewall, reads the host as root, plans again for No changes., and runs drift for No drift.

↓
GATE 3

Every release

Built in GitHub Actions, never on a laptop.

Signed

checksums.txt signed with cosign, keyless, in Sigstore's public log.

Attested

Build provenance for every archive. Check it with gh attestation verify.

Listed

An SBOM beside every archive: what went into the binary.
